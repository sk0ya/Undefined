# プレイヤー画面ワイヤーフレーム（P0）

参加者が画面を開いた直後に「自分は誰で、まず何をするか」を理解し、現在フェーズの未対応タスクから次の行動を選べることを目的にした、実装確認用のワイヤーフレームです。

## 基本レイアウト（デスクトップ）

```text
┌─────────────────────────────────────────────────────────────────────┐
│ REQGAME   フェーズ: ブリーフィング       ルームA   接続中             │
├─────────────────────────────────────────────────────────────────────┤
│ このフェーズの目的: 自分の立場と前提をそろえ、議論の準備をする       │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │ □ 自分のロール・公開プロフィール・秘密情報を読む                 │ │
│ │ □ シナリオの目的・制約・チーム構成を確認する                     │ │
│ │ □ 読み終わったら準備OKを押す                         1/2人       │ │
│ └─────────────────────────────────────────────────────────────────┘ │
│ 完了条件: チーム全員が確認し、準備OKを押す                             │
│ 次: 議論フェーズで質問・要求カード・仕様書を進める                    │
├─────────────────────────────────────────────────────────────────────┤
│ [🎭 あなたのロール] [📖 シナリオ] [✓ 準備OK]                           │
├─────────────────────────────────────────────────────────────────────┤
│ [💬 ヒアリング 未回答2] [📝 要求カード 新着1 / 自分の提出1]             │
│ [📄 仕様書 未記入3]     [🗳 投票 未投票1]                              │
├─────────────────────────────────────────────────────────────────────┤
│ フェーズの詳細（選択したタブ）                                          │
└─────────────────────────────────────────────────────────────────────┘
```

## 表示ルール

1. フェーズバナーの直下に目的、必須行動、完了条件、次の行動を置く。
2. 必須行動はチェック状態と未対応件数を表示し、件数が0になったときだけ完了状態にする。
3. 議論フェーズでは、ヒアリング・要求カード・仕様書の入口をタブの外にも置く。
4. タブのバッジは「未対応」「新着」「自分の提出」「未投票」を区別し、件数0の状態も意味が分かる表示にする。
5. 準備OKは現在フェーズの完了通知であり、自動的に次へ進まないことを説明する。

## フェーズ別の主導線

| フェーズ | 主導線 | 完了の目安 |
| --- | --- | --- |
| ロビー | 参加者名の確認 | hostの開始を待つ |
| ブリーフィング | ロール → シナリオ → 準備OK | 自分の確認が終わる |
| ヒアリング・議論 | 質問 → 要求カード → 仕様書 | 必須行動を確認して準備OK |
| 合意形成 | 要求カード → 投票 | 自分の投票を終える |
| 仕上げ | 仕様書の空欄・例外を確認 | 最終版をチームで確認 |
| 結果発表 | 判断の足跡 → 見落とし → 次回の一手 | 学びを1つ言語化する |

## 狭い画面とアクセシビリティ

- 390px幅ではガイド、クイック導線、選択中タブの順に1列へ並べる。
- ボタンには絵文字だけでなくテキストを付け、色だけで状態を伝えない。
- 入力欄には対応するラベルを付け、キーボードだけでタブ・カード・送信を操作できるようにする。
- 読み込み中、未回答、保存済み、失敗を同じ場所で確認できるようにする。

## 受け入れ確認

- 初回参加者が60秒以内に自分のロールと最初の行動を説明できる。
- 各フェーズで重要な未対応タスクが1画面に収まる。
- 390px幅で横スクロールなしに主要導線を使える。
- AIがなくても質問、議論、仕様書、投票、結果発表を完走できる。
