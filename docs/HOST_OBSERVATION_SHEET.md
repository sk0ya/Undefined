## 開始前チェック

- [ ] host画面を開けた
- [ ] ルームコードを参加者へ共有できた
- [ ] Codexを使う場合、「接続確認」が成功した
- [ ] AIなしで進める場合の手動回答・手動採点の場所を確認した
- [ ] 保存・復帰が必要な場合の再開手順を確認した
