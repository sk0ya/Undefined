# host向け進行ガイド

このガイドは、研修中にhostが画面を探し回らず、ゲームの進行と議論の支援に集中するための短い手順です。

## 開始前（ローカル実行）

1. host PCにNode.js 20+と、ログイン済みのCodex CLIを用意する。
2. リポジトリの`web`ディレクトリで次を実行する。

   ```powershell
   npm install
   npm run host
   ```

3. `http://localhost:5173/#host`を開く。
4. 「🔑 AI設定」で`Codex(host PC)`を選び、「接続確認」が5秒以内に成功することを確認する。失敗した場合は画面に理由が出るので、ブリッジを起動してから再確認する。
5. シナリオを選び、表示された6文字のルームコードを参加者へ共有する。参加リンクをコピーした場合、参加者は公開Pages URLを開く(ホストPCの`localhost`は開かない)。

`npm run host`はゲーム画面とCodexブリッジを同時に起動します。終了するときは同じターミナルで`Ctrl+C`を押します。5173番ポートが別のアプリで使われている場合は、先にそのアプリを停止するか、`REQGAME_HOST_PORT`で別ポートを指定してください。

## 進行

1. **仕様書を作る**：開始するとすぐに作成画面になります。参加者は「準備」でお題・秘密の目標を確認し、「質問」「仕様書」タブを自由に行き来して作成します。読了待ちのフェーズはありません。
2. **採点**：「仕様書の確認完了」を目安に進む。各ルームのAI採点、またはプロンプトのコピーと結果JSONの貼り戻しで採点する。
3. **結果発表**：チーム得点と秘密の個人目標の達成を確認する。実運用テストで見落としを振り返る。

要求カード・投票・追加イベントの操作はありません。全員準備OKでも自動では進みません。
「次のフェーズへ」で進行してください。タイマーは必要なときだけ使えます。

## 操作する場所

- **質問に回答**：未回答の質問へ回答する。NPC自動回答もここで切り替える。
- **ルームの成果物**：選択中ルームの仕様書・質問記録を確認する。
- **ホスト用資料**：シナリオ、秘密情報、隠れ要件を確認する。
- **AI設定**：接続方法を設定する。AIは任意。

仕様書は自動保存されます。同時編集で競合したら、保存済みの内容と手元の下書きから残す方を選びます。
確認完了後も結果発表までは編集できます。採点後に仕様書を変更した場合は再採点してください。

## 接続が切れたとき

ホストのタブは開いたままにしてください。閉じてしまった場合は同じブラウザーで `#host` を開き直すと復帰します。
参加者も同じブラウザー・参加リンクで入り直せます。仕様書の保存状態を確認してから進行してください。
